### 📌 Projetos em destaque

**[Aegis Cast](https://github.com/Rafaleel/Aegis-Cast)** · **[Acessar aplicação](https://aegiscast.onrender.com/)** Aplicação web em beta para compartilhamento de tela, câmera, microfone e chat entre navegadores com WebRTC. Não exige cadastro e mantém o backend restrito à sinalização em memória, com RTCDataChannel, recuperação de ICE e suporte configurável a TURN.

**[book-quote-vault](https://github.com/Rafaleel/book-quote-vault)**
Aplicação full-stack para organizar citações de livros. Backend em Java/Spring Boot (Spring Security, JWT, OAuth2, JPA/Hibernate, PostgreSQL) + frontend em React/Vite/TypeScript com Tailwind CSS.

**[eda-tool](https://github.com/Rafaleel/eda-tool)**
Ferramenta de linha de comando em Python que recebe qualquer CSV e gera automaticamente um relatório HTML interativo com estatísticas, distribuições, correlações e valores ausentes (Pandas + Plotly).

**[ml-pipeline-project](https://github.com/Rafaleel/ml-pipeline-project)**
Pipeline de machine learning de ponta a ponta para previsão de sobrevivência no Titanic, com rastreamento de experimentos via MLflow. Melhor modelo (Regressão Logística) atingiu 83% de acurácia e ROC AUC de 0.87.

**[local-speech-to-text](https://github.com/Rafaleel/local-speech-to-text)**
Aplicação desktop (PySide6) de transcrição de voz em tempo real 100% local usando Whisper, com histórico pesquisável em SQLite e gerenciamento de VRAM da GPU.
